# 🚀 Fastfetch Config

> My personalized configuration for **Fastfetch**. 

---

## ⚙️ Configuration

Before running the config, remember one important detail!

> [!IMPORTANT]
> You must set your own logo path in the `part1.jsonc` file[cite: 1]!

1. Open the `part1.jsonc` file[cite: 1].
2. Locate the path setting and update it to point to the correct resource on your system.
3. Save the file and you're good to go!

---

## 📦 Quick Start

Drop the configuration files into ur system's Fastfetch directory (typically `~/.config/fastfetch/`), add both files to ur zshrc/bashrc and enjoy ur new terminal look!
